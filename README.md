# team-blue/php-util

PHP utility tools.

Collection of helpers used across team.blue PHP packages: `ArrayUtil`, `ScalarUtil`, `StringUtil`, `ImmutableRecordUtil`, `ValueObjectUtil`, a metadata extractor for attributes/docblocks, and a Symfony bundle (`UtilBundle`).

## Installation

```bash
composer require team-blue/php-util
```
